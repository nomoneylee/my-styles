# Pure Vanilla CSS 十大至二十大美學風格 Homepage 系統

本專案為 **100% 完全自建 Pure Vanilla CSS & Vanilla JavaScript** 的 Homepage 美學風格系統庫。完全零 Bootstrap 5 或任何外部框架依賴！

每個風格目錄皆具備獨立的 `style.css`、`script.js`、`index.html` 與詳細的 `README.md` 類別說明文件。包含全套自建原生 UI 元件：Header / Navbar, Hero Section, Color Palette Showcase, Alerts, Typography & Badges, Buttons, Form Controls (Input, Select, Textarea, Checkbox, Radio, Switch, Range), Cards, Accordion, Tabs, Modal, Offcanvas, Progress Bar, Tables 等。

## 🛠️ 開發與視覺規範 (Development Standards)

1. **100% Pure Vanilla CSS/JS**：禁止使用 Bootstrap 5 或任何外部框架 CDN。
2. **完全響應式 RWD 彈性對齊**：所有導覽列、Modal 對話框、表單控制項與表單全數支援從小螢幕手機到 4K 桌機的完美自動適應與防撐爆。
3. **原生自建 UI 元件庫**：每一種風格獨立實作按鈕、標籤、表單輸入框、單選/多選/開關/Slider、卡片、手風琴、分頁 Tab、Modal 彈窗、Offcanvas 側欄、進度條、表格等。
4. **繁體中文維護**：所有文檔、註解與界面文字皆採用規範繁體中文。
