2026 Pure Design System

設計的極致，在於極簡與純粹。

100% 自建 Pure Vanilla CSS & Vanilla JS。零外部框架依賴，大面積留白、蘋果經典深灰與蘋果藍配調。

蘋果極簡專屬色彩系統 (Apple Palette System)

依據極簡與高級設計雜誌風格專屬打造的色彩 Tokens，展現 Primary, Secondary, Accent, Info, Success, Warning, Error 系統色彩：

Primary 炭黑 --ap-color-primary (#1d1d1f)
Secondary 輔助灰 --ap-color-secondary (#86868b)
Accent 蘋果藍 --ap-color-accent (#0066cc)
Info 冰藍 --ap-color-info (#34aadc)
Success 翡翠綠 --ap-color-success (#34c759)
Warning 琥珀橘 --ap-color-warning (#ff9500)
Error 珊瑚紅 --ap-color-error (#ff3b30)

狀態與通知 (Alert Notifications)

Info Notification: 這是以 Ice Blue 展示的系統通知。
Success Notification: 這是以 Emerald Green 展示的成功狀態。
Warning Notification: 這是以 Amber Orange 展示的警告提示。
Error Notification: 這是以 Coral Red 展示的錯誤提醒。

什麼是 Pure Vanilla CSS 設計系統？ ▼
此頁面 100% 不依賴任何第三方 CSS 框架（如 Bootstrap 5），由原生 CSS Variables, Flexbox, CSS Grid 及原生 JavaScript 獨立檔 `script.js` 打造。
如何開關對話框與側邊選單？ ▼
點擊頁面導覽列中的按鈕即可開啟原生的 Modal 對話框或 Offcanvas 側邊視窗。
