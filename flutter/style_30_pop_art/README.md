# Comic Pop Art - Flutter App Template

本專案提供 Comic Pop Art 美式漫畫美波普藝術風格 (Roy Lichtenstein 質感) 的 Flutter 主題與組件樣板。

## 視覺特色
- **經典原色**：大膽高彩美波普經典三原色 (漫畫鮮紅 `#FF2A2A` / 亮黃 `#FFE500` / 漫畫藍 `#0066FF`)。
- **漫畫對話框**：粗黑對話框 (Speech Bubbles)、動作驚嘆標籤 (`BOOM!`, `POW!`)。
- **Halftone 斑點**：幾何 Halftone 網點背景與 3.5px 粗黑手繪線條感。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
