# Cyberpunk Neon Web 模擬說明 (Pure Vanilla)

本目錄包含復古賽博朋克 (Cyberpunk / Neon Dark) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含量子核心監控卡片、霓虹指令輸入框與電競風格 Switch 開關。
- `style.css`: 定義純黑夜幕背景 (#090A0F)、霓虹青 (#00F0FF) / 霓虹粉 (#FF007A) 外發光 Neon Glow 與電競字型 Token。
- `script.js`: 提供系統超頻模擬與霓虹外框發光切換互動。
