# Terminal Dashboard Web 模擬說明 (Pure Vanilla)

本目錄包含高密度儀表板 (High-Density Dashboard / Terminal) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含 HFT 高頻交易節點卡片、CLI 指令輸入框與 FPGA DMA 開關。
- `style.css`: 定義 0px 零圓角、純黑底 (#000000)、螢光綠 (#00FF66) 與 Monospace 等寬字型 Token。
- `script.js`: 提供 CLI 指令執行與 Log 快取清除的硬核控制。
