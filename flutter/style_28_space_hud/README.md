# Space UI / NASA HUD - Flutter App Template

本專案提供 Space UI / NASA HUD 太空艙抬頭顯示器風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：深邃太空黑 (`#050B14`) 搭配螢光青綠 (`#00FFCC`) 與太陽琥珀橘 (`#FF9900`)。
- **網格與刻度**：十字對焦瞄準線、網格電路線條與 HUD 數據儀表。
- **科技感**：高對比度 Monospace 等寬感字體與科幻控制台組件。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
