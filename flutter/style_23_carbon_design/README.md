# IBM Carbon Design - Flutter App Template

本專案提供 IBM 企業級 Carbon Design System 風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：IBM 炭灰基底 (`#161616`)、Carbon 標誌藍 (`#0F62FE`) 與石墨灰。
- **邊框與圓角**：100% 0px 直角邊框、高數據密度與精確的 1px 網格架構線條。
- **組件**：極致簡潔硬朗的企業級儀表板組件與高對比資訊層級。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
