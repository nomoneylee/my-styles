# Soft Organic Web 模擬說明 (Pure Vanilla)

本目錄包含柔和莫蘭迪 (Soft Organic / Warm Editorial) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含龜背竹自然卡片、冥想聲音 Switch 與膠囊按鈕。
- `style.css`: 定義 28px 超大圓角、Stadium 膠囊按鈕、燕麥色 (#F2EFE9) 與鼠尾草綠 (#8A9A86) 莫蘭迪自然 Token。
- `script.js`: 提供冥想模式與修復日誌開啟的簡潔互動。
