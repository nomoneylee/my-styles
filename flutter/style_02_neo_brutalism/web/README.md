# Neo-Brutalism Web 模擬說明 (Pure Vanilla)

本目錄包含新粗獷主義 (Neo-Brutalism) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含潮牌限定商品卡片、優惠碼輸入框與 Switch 開關。
- `style.css`: 定義純黑 3px 邊框、硬邊 Offset 塊陰影與高飽和度潮流顏色 Token（#FFE66D 黃、#FF6B6B 粉紅、#4ECDC4 青綠）。
- `script.js`: 提供搶購購物車與閃電主題撞色效果的互動邏輯。
