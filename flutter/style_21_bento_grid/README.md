# Bento Grid (AI Dashboard) - Flutter App Template

本專案提供 AI Dashboard Bento Grid 風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：深鋅灰背景 (`#09090B`)、霓虹藍紫 (`#6366F1`) 與螢光青色 (`#06B6D4`)。
- **網格與邊框**：卡片式 Bento 便當盒網格切分，1px 細致玻璃光澤邊框 (`#27272A`)。
- **圓角**：現代科技幾何圓角 (16px)。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
