# Apple Minimal Web 模擬說明 (Pure Vanilla)

本目錄包含極簡科技風 (Apple-style Minimalist) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，呈現 Apple Minimal 風格的卡片、按鈕、輸入框與 Switch 開關。
- `style.css`: 定義 20px / 16px 大圓角、柔和微陰影與 `#F5F5F7` 極簡科技風 Token。
- `script.js`: 提供按鈕同步與模擬狀態重置的簡單互動邏輯。
