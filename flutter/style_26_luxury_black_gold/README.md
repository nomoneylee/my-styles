# Luxury Black & Gold - Flutter App Template

本專案提供 Luxury Black & Gold 奢華黑金尊爵風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：曜石黑背景 (`#0B0B0E`) 搭配皇家璀璨金 (`#D4AF37`) 與香檳金 (`#E5C158`)。
- **金絲邊框**：細緻 1px 金絲光澤邊框 (`#3A321E`) 與高級暗光亮影。
- **尊爵質感**：適用於 VIP 會員卡、高階金融私人銀行與奢華品牌 App 介面。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
