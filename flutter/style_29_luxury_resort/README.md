# Luxury Hotel / Resort - Flutter App Template

本專案提供 Luxury Hotel / Resort 頂級渡假飯店風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：沉穩墨綠 (`#1B3B2B`)、暖沙米白背景 (`#F7F4EF`) 與香檳金 (`#C5A059`)。
- **邊框與字體**：優雅典雅字體排版、細緻金絲線條與五星級 SPA 放諾質感。
- **極致放鬆**：適合精品酒店訂房、高級度假村、SPA 會館與頂級餐飲 App。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
