# Retro Y2K Web 模擬說明 (Pure Vanilla)

本目錄包含復古 Y2K (Retro Y2K / OS Classic) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含 Windows 95 音樂播放視窗、軟碟機 Switch 與 3D 按下按鈕。
- `style.css`: 定義 0px 直角、3D Bevel 亮暗邊框、經典電腦灰 (#C0C0C0) 與深藍標題列 (#000080) Token。
- `script.js`: 提供 CMD 執行與經典 90s 電腦視窗互動控制。
