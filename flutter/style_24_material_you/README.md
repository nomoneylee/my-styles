# Material You (Material 3 Expressive) - Flutter App Template

本專案提供 Google Material 3 / Material You 動態色彩與表現力風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：Google Material 3 調和 Tonal Palette (`#6750A4` / `#E8DEF8` / `#7D5260`)。
- **圓角**：28px 超大流線圓角、Stadium 膠囊邊框與動態表現力形狀 (Expressive Shapes)。
- **組件**：標誌性 Floating Action Button (FAB)、Tonal 膠囊 Segment、標準 Material 3 Cards 與彈窗。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
