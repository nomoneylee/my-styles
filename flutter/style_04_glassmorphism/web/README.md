# Glassmorphism Web 模擬說明 (Pure Vanilla)

本目錄包含玻璃擬物風 (Glassmorphism / Frost UI) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含半透明晶瑩 Web3 質押卡片、合約輸入框與 Switch 開關。
- `style.css`: 定義 15% 半透明白卡片背景、微光 1px 細邊框、BackdropFilter 毛玻璃與冰天藍 (#38BDF8) / 霓紫 (#C084FC) 暗色漸層 Token。
- `script.js`: 提供質押發起模擬與光暈動態縮放效果。
