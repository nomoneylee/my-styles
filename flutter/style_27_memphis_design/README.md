# Memphis Design - Flutter App Template

本專案提供 80 年代 Memphis Design 孟菲斯後現代主義風格的 Flutter 主題與組件樣板。

## 視覺特色
- **撞色**：大膽鮮艷撞色 (亮粉 `#FF007F` / 電光黃 `#FFE600` / 湖水綠 `#00E5FF`)。
- **線條與印花**：3px 粗黑邊框、幾何斑點波浪紋理與硬派 4px 實心硬黑陰影。
- **趣味性**：80 年代經典復古幾何切分與活潑跳躍的 Pop Art 音符視覺。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
