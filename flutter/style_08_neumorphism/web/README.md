# Neumorphism Web 模擬說明 (Pure Vanilla)

本目錄包含新擬物風 (Neumorphism / Soft UI) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含智慧音響軟擬物浮雕卡片、凹陷輸入框與立體 Switch。
- `style.css`: 定義同色系背景 (#E0E5EC)、右上亮影 (#FFFFFF) 與左下暗影 (#A3B1C6) 雙重擬質影 Token。
- `script.js`: 提供浮雕參數儲存與中樞重置的觸覺互動控制。
