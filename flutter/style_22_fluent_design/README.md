# Microsoft Fluent 2 - Flutter App Template

本專案提供微軟 Microsoft Fluent Design System 2 風格的 Flutter 主題與組件樣板。

## 視覺特色
- **配色**：Fluent 品牌藍 (`#0078D4`)、柔和亞克力背景 (`#F3F3F3`) 與中性石炭色。
- **邊框與圓角**：8px Fluent 標準圓角、輕度亞克力光澤與階層深度陰影 (Elevation Depth)。
- **控制項**：現代 Windows 11 / Fluent 2 標準按鈕、切換器與圓潤條狀卡片。

## 展示
可在 `web/index.html` 直接預覽 Pure Vanilla Web 展示頁面。
