# Modern SaaS Web 模擬說明 (Pure Vanilla)

本目錄包含扁平化微漸層 (Modern Flat / Vibrant Gradient) 的 Web 模擬展示畫面，完全採用原生 Pure Vanilla CSS 與 JavaScript 打造。

## 檔案說明
- `index.html`: Web 展示頁面結構，包含 ARR 營收分析卡片、企業網域輸入框與 SaaS 自動化 Switch。
- `style.css`: 定義適中 12px 圓角、高明度雙色漸層 (靛藍 #6366F1 ➔ 天空藍 #3B82F6) 與彩色半透明陰影 Token。
- `script.js`: 提供 Pro 方案升級與 CSV 報表匯出的簡潔互動控制。
